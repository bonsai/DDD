# Templates Contract

**Type:** template-spec
**Status:** accepted
**Source Issues:** #7 #10 #18

Templates are executable social contracts shared by humans, AI agents, and reviewers.

## Required metadata

```yaml
id: DDD-XXXX
type: <document-type>
status: draft|review|accepted|deprecated|superseded
title: <title>
created: <date>
updated: <date>
related_issues: []
relations: []
evidence: []
supersedes: []
```

## Required semantic sections

Every template must make purpose, sources, status, relationships, and unresolved questions explicit where applicable.

Templates may evolve without changing the ontology. Ontology, document types, templates, and workflow are separate layers.
