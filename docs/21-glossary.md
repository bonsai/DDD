# DDD Glossary

**Type:** glossary
**Status:** accepted
**Source Issues:** #17 #18 #26

| Term | Definition |
|---|---|
| Issue | unit of uncertainty / question |
| Document | persistent shared knowledge |
| Evidence | support for a claim |
| Decision | adopted choice |
| Change | implementation modification |
| Test | verification activity/result |
| Release | delivered version/change |
| Feedback | observed response that may generate uncertainty |
| PRD | product intent and scope |
| RFC | pre-decision proposal |
| ADR | durable decision record |
| Design | implementation elaboration |
| Traceability | typed links between knowledge artifacts |
| Source of truth | artifact authoritative for a particular knowledge role |

Issue type and Document type are separate axes.
