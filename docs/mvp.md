# MVP

**Minimum Viable Product** — the smallest product scope that can be delivered to provide real user value and generate evidence from actual use.

## Purpose

MVP answers:

> What is the smallest product worth delivering?

## Structure

```yaml
id: MVP-001
product: product name
problem: user problem
users: target users
core_value: value delivered
in_scope:
  - essential capability
out_of_scope:
  - deferred capability
success_criteria:
  - criterion
kpi:
  - KPI-001
```

## Rules

- MVP is a product scope, not a prototype.
- Include only capabilities necessary to deliver the core value and obtain evidence.
- Explicitly record what is out of scope.
- Connect success criteria to measurable outcomes where possible.

## Relationship

```text
PRD → MVP → BUILD → OPERATE → KPI
```
