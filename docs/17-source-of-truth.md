# Source of Truth Policy

**Type:** policy
**Status:** accepted
**Source Issues:** #24 #25 #27

## Canonical ownership

- **Issue:** source of unresolved questions
- **Accepted Document:** source of shared knowledge
- **ADR:** source of adopted decisions
- **Code:** source of implementation behavior
- **Test/Evidence:** source of verification results
- **Release:** source of delivered version
- **Feedback:** source of observed response

Chat is a working surface and input channel. It is not authoritative.

## Promotion rule

When a conversation contains durable knowledge, promote it to the appropriate canonical artifact. Do not rely on context windows as a knowledge store.
