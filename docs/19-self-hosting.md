# Self-Hosting DDD

**Type:** principle
**Status:** accepted
**Source Issues:** #9 #19 #23 #27

DDD must itself be developed using DDD.

## Meta-cycle

`Issue → Research → RFC → ADR → Document → PR → Test → Feedback → Issue`

The DDD repository is therefore both:

1. the specification of the method, and
2. an experiment in applying the method.

If the method cannot explain and trace its own evolution, the method is incomplete.

Issue history remains the raw material; canonical Documents are consolidated knowledge derived from that history.
