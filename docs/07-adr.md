# ADR

**Type:** adr
**Status:** accepted
**Source Issues:** #3 #6 #11 #13

ADR records a consequential decision and preserves why it was made.

## Canonical sections

1. Context
2. Decision
3. Alternatives considered
4. Rationale
5. Consequences
6. Rejected alternatives
7. Status
8. Supersedes / Superseded by
9. Related Issues / RFCs / Designs

## Rule

An ADR is not a proposal. A draft ADR may propose a decision, but only an accepted ADR is a source of adopted decision.

## Why

Without ADRs, important reasoning disappears into chat, meetings, or code history. ADRs preserve decision lineage.
