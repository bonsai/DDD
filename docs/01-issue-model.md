# Issue Model

**Type:** model
**Status:** accepted
**Source Issues:** #2 #17 #26

## Definition

An Issue is the canonical unit of uncertainty. It represents something not yet sufficiently known, decided, verified, or resolved.

## Issue is not

- merely a task
- merely a bug
- merely a question in chat
- a Document type

## Typical forms

`question / problem / observation / change-request / defect / uncertainty`

## Contract

Every meaningful Issue should state:

- what is uncertain
- why it matters
- current context
- expected resolution
- related Documents or Evidence

## Resolution

An Issue may be resolved by a Document, Decision, Change, Test result, or explicit rejection. Resolution must remain traceable.
