# Document Taxonomy

**Type:** taxonomy
**Status:** accepted
**Source Issues:** #3 #10 #19 #23

Document types are semantic roles, not workflow states.

| Type | Role |
|---|---|
| foundation | principles and definitions |
| vision | desired future |
| PRD | product purpose, value, scope |
| requirement/spec | observable behavior |
| research | accumulated investigation |
| experiment | controlled learning |
| RFC | proposal and alternatives before decision |
| ADR | adopted decision and rationale |
| design | implementation structure |
| test plan/report | verification method/result |
| evidence | support for claims |
| operations | deployment/runtime knowledge |
| retrospective/postmortem | learning from operation |
| glossary/ontology | shared vocabulary/model |

A document type must not be confused with an Issue type or lifecycle status.
