# RFC

**Type:** rfc
**Status:** accepted
**Source Issues:** #3 #7 #26

RFC is the document for proposing an answer before it becomes a decision.

## Canonical sections

1. Problem / Issue
2. Context
3. Goals
4. Non-goals
5. Constraints
6. Options
7. Evaluation criteria
8. Recommendation
9. Risks
10. Migration / rollout
11. Open questions
12. Decision target

RFC must clearly distinguish proposal from adopted decision. Once accepted, its decision should be captured in an ADR when the choice has durable consequences.
